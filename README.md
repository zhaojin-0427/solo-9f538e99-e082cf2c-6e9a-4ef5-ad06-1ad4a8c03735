# 封闭池塘标记重捕估算系统

第二轮调查有些鱼的标记号看不清：先按两轮独立抽样估出鱼数范围，再决定要不要补查。
Flask + SQLite 单页应用，支持 `docker compose` 一键启动。

## 功能

- **上传两轮 CSV**（各 1～300 条）：
  - 首轮：表头 `tag`，每行一个放回鱼的**唯一标记号**；
  - 次轮：表头 `sample_no,status,candidates`，每行填唯一样本号、标记状态
    （`有标` / `无标` / `看不清`）和来自首轮的候选标记号（`;` 分隔，可空）。
- **配对规则**：有标必配、无标不配、看不清可配可不配、每个首轮标记只用一次。
  用二分图匹配（Hopcroft-Karp）求：
  - **最少重捕数** = 覆盖全部有标样本的匹配（附一套配对）；
  - **最多重捕数** = 在此基础上让"看不清"样本尽量增广（附一套配对）。
- **鱼数估算**：`N = 首轮条数 × 次轮条数 ÷ 重捕数`，按最少/最多重捕给出估算两端；
  重捕数为 0 的端点标为**不可估**。
- **逐条更正**：网页上每条次轮记录带**版号**，按所见版号提交更正（乐观锁），
  成功当次显示并保存新估算，版号 +1。
- **无解证明**：若无法覆盖全部有标样本，按霍尔定理给出一组有标样本及其候选号并集，
  证明"不同候选号 < 样本数"。
- **失败保护**：过期（版号不符）、无解或写入失败时，本次修改不生效，
  上次记录与估算原样保留；数据存于 SQLite 文件，**重启后仍可查看**。

## 启动

### Docker Compose（推荐）

```bash
docker compose up --build
```

访问 http://localhost:8000 。SQLite 数据库保存在命名卷 `appdata` 中，容器重建不丢数据。

### 本地运行

```bash
pip install -r requirements.txt
python app.py            # 默认 0.0.0.0:8000，DB 为 ./markrecap.db
```

环境变量：`DB_PATH`（数据库路径）、`PORT`（端口）、`SECRET_KEY`（会话密钥）。

## CSV 格式

`examples/round1.csv`：

```csv
tag
T01
T02
```

`examples/round2.csv`：

```csv
sample_no,status,candidates
s01,有标,T01
s02,有标,T02;T03
s07,无标,
s13,看不清,T10;T11
```

- 编码 UTF-8（可带 BOM）；候选号可用 `;` `；` `|` `/` `、` `,` 或空格分隔。
- 表头支持中文别名：`标记号` / `样本号` / `状态` / `候选号`。
- 候选号必须来自首轮；`无标` 行不得填写候选号。

## 测试

```bash
python3 -m pytest test_app.py -q
```
